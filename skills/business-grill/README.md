# business-grill

`business-grill` — переносимий Agent Skill для жорсткої, але конструктивної перевірки бізнес-гіпотез, інвестицій, операційних моделей, комерційних пропозицій і кошторисів.

Він не “підтверджує ідею”, а допомагає власнику отримати захищуване рішення **GO / VALIDATE / PIVOT / STOP** з доказами, межами ризику, kill-критеріями та моделлю делегування. Скіл оптимізований під ціль “володіти бізнесом і контролювати систему”, а не стати розробником чи незамінним оператором.

## Принципи

- спочатку доступні факти, потім питання;
- залежні рішення розглядаються у правильному порядку;
- питання ставляться короткими раундами з рекомендованою відповіддю;
- твердження відокремлюються від фактів, припущень та рішень;
- оцінюється не лише ринок, а й делегованість та реальне навантаження власника;
- те, що не можна вирішити розмовою, перетворюється на обмежений експеримент;
- будь-яка дія поза аналізом потребує окремої явної авторизації;
- програмне забезпечення не будується, доки не доведено конкретний ручний крок або рішення, яке воно покращує.

## Встановлення в Codex

Скопіюйте всю папку `business-grill` до персонального каталогу skills:

```text
%USERPROFILE%\.codex\skills\business-grill
```

Почніть нову сесію та викличте явно:

```text
Use $business-grill to stress-test this hypothesis: ...
```

Codex також може вибрати скіл автоматично, коли запит відповідає його опису.

## Встановлення в Claude Code

Для персонального використання скопіюйте папку до:

```text
~/.claude/skills/business-grill
```

Для одного проєкту — до:

```text
.claude/skills/business-grill
```

Після перезапуску сесії попросіть Claude використати `business-grill` для конкретної гіпотези. Claude Code автоматично знаходить skills із `SKILL.md` у цих каталогах.

## Швидкий старт

```text
Використай business-grill. Я думаю запустити [пропозиція] для [сегмент].
Моя ціль — володіти системою, а не виконувати операції особисто.
Ліміт перевірки: [сума] і [час]. Потрібне рішення GO/VALIDATE/PIVOT/STOP.
```

Для кошторису:

```text
Використай business-grill у режимі document review. Перевір цей кошторис read-only:
обсяг, кількості, одиничні ставки, дублікати, пропуски, виключення, графік оплат,
ризики та питання підряднику. Нічого не надсилай і не погоджуй.
```

## Типовий результат

Скіл повертає рішення і рівень упевненості, тезу, fatal gates, оцінку зі 100 балів, реєстр доказів, сильні контраргументи, модель делегування, обмежений наступний тест, kill-критерії та список того, що поки не слід будувати чи купувати.

## Походження підходу

Скіл натхнений принципами Grill-Me: досліджувати доступні факти до запитань, проходити дерево рішень за залежностями, ставити питання раундами, давати рекомендовану відповідь і не діяти до узгодження. Він не копіює оригінальний skill і додає окрему бізнес-архітектуру: доказові рівні, зважену оцінку, fatal gates, GO/VALIDATE/PIVOT/STOP, делегованість, owner-load, kill-критерії та read-only межу.

## Межі

Скіл не замінює юриста, бухгалтера, кошторисника, інженера технічного нагляду чи іншого ліцензованого фахівця. Він структурує рішення, докази й запитання; професійну сертифікацію виконує людина з відповідними повноваженнями.
