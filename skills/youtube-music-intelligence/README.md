# YouTube Music Intelligence

A reusable Agent Skill for evidence-backed YouTube music-channel research using the vidIQ connector or independently supplied exports.

The skill helps benchmark comparable music channels, find breakout releases, compare Shorts and long-form performance, assess titles/thumbnails, and design controlled publishing experiments.

- Main instructions: [SKILL.md](SKILL.md)
- Connector guidance and credit policy: [references/vidiq-adapter.md](references/vidiq-adapter.md)
- Output template: [assets/report-template.md](assets/report-template.md)

## Installation

Copy this directory as a self-contained skill to a compatible agent's skills folder, or reference it from your repository's agent instructions.

## Privacy and operations

This directory contains no private organization profile, credentials or actual competitor research. The skill is read-only by default, requests authorization before spending connector credits, and never uploads or publishes videos on its own.
